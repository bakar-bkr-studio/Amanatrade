# SOURCE QUALITY RULES — AmanaTrade

## Objectif de ce document
Définir les règles de qualification des sources utilisées dans les recherches AmanaTrade.

---

## Niveaux de fiabilité des sources

| Niveau | Label | Description | Exemples |
|---|---|---|---|
| A | ✅ Source primaire fiable | Données officielles, études académiques, rapports institutionnels datés | CBN reports, NBS Nigeria, World Bank, études peer-reviewed |
| B | ⚠️ Source secondaire acceptable | Articles journalistiques de référence, rapports d'organisations reconnues | TechCabal, Nairametrics, McKinsey Africa, GSMA |
| C | ⚠️ Source à confirmer | Blogs, estimations d'industrie, témoignages isolés | Articles de blogs, posts LinkedIn, anecdotes terrain |
| D | ❌ Source insuffisante | Non daté, anonyme, non vérifiable | "On dit que…", statistiques sans source |

---

## Règles d'utilisation

1. **Toujours citer la source** : Nom de l'organisation, titre du document, date de publication, URL ou référence.
2. **Toujours indiquer la date d'accès** pour les sources web.
3. **Ne jamais utiliser une donnée économique ou réglementaire de plus de 3 ans** sans vérifier qu'elle est toujours valide.
4. **Signaler les contradictions** : Si deux sources donnent des chiffres différents, les deux doivent être mentionnées.
5. **Distinguer : données Nigeria vs données Afrique sub-saharienne** — ne pas extrapoler sans le signaler.
6. **Terrain > statistiques** : Une donnée issue d'entretiens terrain avec des utilisateurs Kano prime sur une étude générique.

---

## Formule de citation standard

```
[NOM DE LA SOURCE] (ANNÉE). *Titre du document*. Organisation. URL. Consulté le JJ/MM/AAAA.
Niveau : A / B / C / D
```

---

## Ce qu'on ne fait JAMAIS
- Présenter une estimation comme un fait vérifié.
- Utiliser des chiffres de mémoire sans les sourcer.
- Ignorer des sources qui contredisent nos hypothèses.
